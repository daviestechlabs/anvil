# Anvil contributor instructions

Read README.md and CONTRIBUTING.md before editing this package.
This repository contains the open source core exported from an authoritative private Anvil repository.
Contributors work through public issues and pull requests.
Maintainers review shared fixes in the authoritative repository before exporting them here.

Keep public changes reproducible in that source or its export templates.
Do not copy private history, integrations, credentials, endpoints, data, or production receipts into this repository.
Do not configure production deployments to follow this repository.
Follow the tests and execution guarantees in CONTRIBUTING.md and docs/API.md.
