# Security policy

The project is alpha and has no stable supported release yet.
Maintainers review security fixes for the default branch.
Use reviewed, digest-pinned images and explicit namespace permissions.
Argo, storage, authentication, and database configuration remain administrator responsibilities.
External template inputs need their own content and authorization checks.

## Report a vulnerability

Use GitHub's private vulnerability reporting feature when the repository enables it.
If private reporting is unavailable, open an issue requesting a private contact channel.
Do not include exploit details, credentials, or private data in that issue.
Include the affected commit, reproduction steps, impact, and proposed mitigation in the private report.
Maintainers coordinate disclosure after reviewing the report.
There is no guaranteed response-time agreement.
